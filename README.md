# Rogue — Go + tcell

[Русский](README.md) | [English](README.en.md)

Rogue — консольная пошаговая игра об исследовании случайных подземелий.
Цель — пройти 21 этаж, сражаясь с противниками, собирая предметы и находя выходы.
Игра написана на Go. Для интерфейса используется
[`github.com/gdamore/tcell/v2`](https://github.com/gdamore/tcell/tree/v2),
для сохранений — стандартная библиотека `encoding/json`. C, cgo и ncurses не нужны.

## Запуск

Нужен Go 1.25 или новее и обычный интерактивный терминал, например Windows Terminal.
Из каталога, где находится этот README:

```powershell
go mod download
go run ./rogue/cmd
```

Сборка Windows:

```powershell
go build -o bin/rogue.exe ./rogue/cmd
./bin/rogue.exe
```

Для воспроизводимой генерации: `go run ./rogue/cmd -seed 42`.
Путь сохранений задаётся флагом `-save-dir`, по умолчанию это `saves/rogue.json`
относительно рабочего каталога. Сохраняйте один и тот же рабочий каталог при запуске.
Минимальный размер терминала — 60×20; карта прокручивается за персонажем.
При размере 80×41 вся карта и интерфейс помещаются на экране.

## Управление

| Клавиша | Действие |
| --- | --- |
| N / C | Новая игра / продолжить в главном меню |
| Enter | Продолжить игру; если сохранения нет — начать новую |
| WASD или стрелки | Передвижение; движение во врага — атака |
| H | Выбрать оружие, 1–9; 0 — убрать в рюкзак |
| J / K / E | Еда / эликсир / свиток, затем 1–9 |
| Пробел или точка | Пропустить ход |
| R | Таблица рекордов |
| Esc | Вернуться из рюкзака в игру; в главном меню — продолжить текущую игру |
| M | Открыть главное меню во время игры |
| Q или Ctrl+C | Сохранить и выйти |

Поддерживается русская раскладка на тех же физических клавишах: N/Т, C/С,
WASD/ЦФЫВ, H/Р, J/О, K/Л, E/У, M/Ь, R/К, Q/Й.

Если окно открывается, но ничего не происходит, нажмите Enter или N/Т.
Движение начинается после выбора новой или сохранённой игры в главном меню.
При сообщении `Resize terminal` увеличьте окно хотя бы до 60×20.
В Windows используется родной консольный режим tcell; игру можно запускать
из Windows Terminal или двойным щелчком по `bin/rogue.exe`.

Игрок — `@`, выход — `>`, дверь — `+`, дверь с найденным ключом — `/`.
Ключи `k` и двери бывают красными, синими и жёлтыми.
Предметы: `%` — еда, `!` — эликсир, `?` — свиток, `)` — оружие.
Противники: `z` — зомби, `v` — вампир, `g` — привидение,
`O` — огр, `s` — змей-маг, `m` — раскрытый мимик. Мимик до боя выглядит как еда.

### Оружие

Нажмите H: строка `In hand` показывает оружие в руках и его урон,
а ниже отдельно перечислено оружие в рюкзаке. Выбор 1–9 **экипирует** предмет:
он переходит из рюкзака в руку и автоматически применяется при атаке движением во врага.
Поэтому выбранное оружие исчезает из списка рюкзака, но остаётся в строке `In hand`
и на панели игрового экрана. При выборе другого оружия предыдущее падает на
соседнюю клетку — его можно подобрать обратно, наступив на неё.

Выбор 0 убирает оружие из рук **в рюкзак**, сохраняя его. Esc закрывает рюкзак
без смены оружия и без хода; повторный Esc в игре ничего не делает.
В главное меню можно перейти по M. Экипировка и снятие оружия тратят один ход.

## Возможности

- 21 этаж, девять случайных комнат в сетке 3×3, коридоры на основе DFS.
- Проверка доступности комнат, ключей и выхода с учётом состояния замков через BFS.
- Пошаговые бои, шесть типов противников и их особенности, преследование через BFS.
- Рюкзак: до девяти предметов каждого типа, расходуемые предметы, смена оружия.
- Временные эликсиры, постоянные свитки, рост максимального здоровья.
- Туман войны, лучи Брезенхэма, память о стенах посещённых комнат и коридорах.
- Настройка сложности следующих этажей по потерянному здоровью и состоянию игрока.
- Полное JSON-состояние после каждого хода и перехода: карта, акторы, рюкзак,
  эффекты, ключи, статистика, состояние генератора случайных чисел.
- История побед и поражений с сортировкой по сокровищам; завершённую игру нельзя
  продолжить. Запись результата и удаление активной сессии происходят вместе.

Сокровища начисляются только за победы над противниками. Меню, изменение размера
терминала, неверный выбор предмета и движение в стену не расходуют ход.
N в главном меню заменяет текущее сохранение новой игрой.

## Архитектура

- `rogue/domain` — сущности, генерация, бой, AI, видимость и интерфейс репозитория.
  Не импортирует tcell, presentation или datalayer.
- `rogue/presentation` — экран tcell, преобразование клавиш, отображение кадров.
- `rogue/presenter` — игровой цикл, меню, преобразование состояния в кадр.
- `rogue/dataLayer` — JSON-хранилище, проверка состояния, атомарная замена файла.
- `rogue/cmd` — точка входа и связывание зависимостей.

## Проверки

```powershell
go test ./...
go vet ./...
```

Тесты проверяют генерацию на разных этажах и seed, прохождение 21 этажа без
противников, ограничения инвентаря, особенности боя, истечение эликсиров,
точное восстановление сохранения и случайной последовательности, историю,
защиту повреждённого JSON от перезаписи и отрисовку через `tcell.SimulationScreen`.
